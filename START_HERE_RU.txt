БЫСТРО ПОСМОТРЕТЬ НОВЫЙ ДИЗАЙН

Откройте preview.html — снимки нового интерфейса без установки.
Для интерактивной демонстрации: установите Node.js 24, выполните
npm ci и npm run dev, затем добавьте /demo к адресу из терминала.
В /demo используются только демонстрационные данные, формы не сохраняются.
Для работы со своими данными выполните настройку ниже.

KARVEN CRM — запуск проекта

1. Распакуйте архив. Откройте папку Karven в терминале.
2. Установите Node.js 24 LTS, если его ещё нет.
3. Выполните: npm ci
4. Скопируйте .env.example в .env.local.
   Windows PowerShell: Copy-Item .env.example .env.local
   Linux/macOS: cp .env.example .env.local
5. В .env.local задайте CRM_ADMIN_USER и собственный CRM_ADMIN_PASSWORD
   (от 12 до 128 символов). Не используйте пароль из чужих примеров.
6. Выполните: npm run dev
7. Откройте в браузере адрес, напечатанный терминалом (порт 3000).
   Войдите с логином и паролем из шага 5.

При первом запуске создаются новая локальная база и первый владелец.
В архиве нет ваших паролей и локальной базы. Поэтому приложение начнёт
с пустыми списками. Снимки демонстрационного интерфейса — preview.html.
Это файл для просмотра, а не интерактивная версия приложения.

Полное описание функций и ограничений: README.md.
Архитектура: docs/architecture.md.
Проверки: npm test; npm run typecheck; npm run build.

Только один процесс приложения может работать с одной папкой data/postgres.
Для просмотра на своём компьютере сервер и домен не нужны.
Текущая версия не предназначена для публикации в Интернет без подготовки.
