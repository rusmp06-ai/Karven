# Установка KARVEN на устройство

Открыть https://karvencrm.netlify.app/install после публикации версии с установкой приложения.

## Windows и macOS

В Chrome или Microsoft Edge нажать «Установить KARVEN» на странице установки, если браузер показывает эту кнопку. Либо воспользоваться значком установки в адресной строке или меню браузера: Chrome → «Трансляция, сохранение и отправка» → «Установить страницу как приложение»; Edge → «Приложения» → «Установить этот сайт как приложение». Формулировки зависят от версии браузера.

Подтвердить установку и при предложении включить создание ярлыка на рабочем столе либо закрепление на панели задач. После этого CRM запускается в отдельном окне. Если ярлык автоматически не создан, открыть установленное приложение в меню «Пуск» и использовать доступные в Windows команды закрепления.

Это устанавливаемое веб-приложение, отдельный EXE-файл не требуется. Авторизация и роли остаются прежними. Обновления приложения загружаются с сайта; при обновлении открытого старого окна его можно перезапустить или обновить.

## Телефон

Android: Chrome → «Установить приложение» / «Добавить на главный экран». iPhone: Safari → «Поделиться» → «На экран Домой».

## Интернет и данные

Для работы с общей базой, рейсами, бронями и оплатами нужен интернет. При отсутствии сети форма не отправляет операцию и сохраняет введённый черновик до закрытия или перезагрузки страницы. После подключения оператор отправляет его повторно вручную; автоматической очереди офлайн-операций нет.

При подключённом интернете service worker не оборачивает ответы и не вмешивается в онлайн-навигацию и обновление карточек после сохранения. Service worker сохраняет только общедоступный файл `/offline.html`. HTML CRM, ответы API, серверные действия, сведения о клиентах, пароли и токены в Cache Storage не записываются. При холодном открытии без сети показывается общая страница подключения; она не содержит данных клиента. Рабочие данные ранее открытой вкладки могут оставаться в её оперативной памяти до закрытия, как в обычном браузере.

Проверки в Chromium охватывают манифест и реальные PNG-иконки, вызов установки по нажатию, работу без сети, сохранение черновика, повторную отправку после подключения и отсутствие личных страниц в кэше. Создание системного ярлыка и системный диалог установки проверяются на устройстве владельца.

Итоговая проверка: производственная сборка и проверка типов прошли; 20 браузерных сценариев в Chromium на изолированной PostgreSQL прошли, включая прежние операции CRM и три сценария установки/работы без сети.
